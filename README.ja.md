# 気仙沼 観光マップ

日本の気仙沼市の観光スポットをインタラクティブな地図上に表示するシンプルなWebアプリケーションです。このプロジェクトは気仙沼市のオープンデータを視覚化し、各スポットを地図上に表示するとともに、詳細情報をテーブルビューで提供します。

## デモ

**ライブデモ: https://github.com/code4fukui/kesennuma-kanko

## 機能

- **インタラクティブな地図**: 気仙沼市の観光スポットを地図上に表示します。
- **詳細情報**: 地図上のピンをクリックすると、名前、営業時間、料金など、各スポットの詳細情報を確認できます。
- **データテーブル**: 地図のすぐ下に、ソート可能なテーブル形式で生データを表示します。
- **静的サイト**: バックエンドを必要とせず、すべてブラウザ上で動作します。

## 仕組み

このアプリケーションは、単一の `index.html` ファイルで構成されており、モダンなWeb Componentsを使用してローカルのCSVファイルから地図とデータテーブルをレンダリングします。

- **`<csv-map>`**: CSVデータを地図上に表示するための、[Code for Fukui](https://github.com/code4fukui/csv-map) のコンポーネント。
- **`<csv-viewer>`**: CSVデータをHTMLテーブルで表示するための、[Code for Sabae](https://github.com/code4sabae/js) のコンポーネント。

## データソース

このプロジェクトでは、[気仙沼市オープンデータライブラリ](https://www.kesennuma.miyagi.jp/sec/s021/010/020/130/20200218174617.html#sightseeing)が提供する「観光施設情報」データセットを利用しています。

本リポジトリには、データのコピーが `20220701_kankou_shisetsu.csv` として含まれています。

## はじめに

静的Webサイトであるため、ビルド手順なしでローカルで実行できます。

1. リポジトリをクローンします:
    ```bash
    git clone https://github.com/code4fukui/kesennuma-kanko.git
    ```
2. プロジェクトのディレクトリに移動します:
    ```bash
    cd kesennuma-kanko
    ```
3. Webブラウザで `index.html` ファイルを開きます。

このサイトは、`main` ブランチにプッシュされるたびにGitHub Pagesへ自動的にデプロイされます。
